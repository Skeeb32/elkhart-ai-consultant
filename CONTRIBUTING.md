# Contributing

Use Node 22.13+ (Node 24 LTS recommended). Install with `npm ci`, create a feature branch, and keep changes focused. Run `npm run typecheck`, `npm test`, and `npm run build`. For UI changes, verify desktop/mobile layouts, keyboard navigation, honest demo labels, links and empty/error states.

Do not commit secrets or customer records. Keep service/pricing content in configuration, AI logic behind its contract and client portal components separate from marketing pages. Include what changed and how you verified it in a pull request. Do not claim live integrations or measurable client outcomes without evidence.
